# Más y Atrás — Sitio web

Sitio oficial del dúo Más y Atrás (Santiago Silberstein y Germán Farías).

## Estructura
- `index.html` — página principal (single-file: HTML + CSS + JS)
- `assets/img/` — fotos y portadas
- `assets/audio/` — tracks en mp3

## Publicar con GitHub Pages
1. Subí este contenido a un repo (puede ser público o privado).
2. Andá a **Settings → Pages**.
3. En "Source" elegí la rama principal (`main`) y carpeta `/ (root)`.
4. Guardá. El sitio va a quedar disponible en `https://<tu-usuario>.github.io/<nombre-repo>/`.
